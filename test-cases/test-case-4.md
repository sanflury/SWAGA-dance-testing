## Тест-кейс №4: Адаптивность на разных устройствах

**Описание:** Проверить корректное отображение сайта на разных разрешениях экрана

**Предусловие:** DevTools открыты, режим эмуляции устройств включён

**Шаги:**
1. Открыть DevTools → Toggle device toolbar
2. Выбрать iPhone SE (375px) — проверить верстку
3. Выбрать iPad (768px) — проверить верстку
4. Выбрать Desktop (1440px) — проверить верстку

**Ожидаемый результат:** На всех разрешениях блоки не наезжают друг на друга, текст читаемый, кнопки кликабельны

**Вид тестирования:** черный ящик, UI-тестирование, тестирование адаптивности

**Известные проблемы:** мобильная версия сверстана без принципа mobile-first, возможны проблемы с отображением
