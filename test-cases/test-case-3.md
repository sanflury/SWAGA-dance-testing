## Тест-кейс №3: Отображение сайта в разных браузерах

**Описание:** Проверить корректное отображение сайта в основных браузерах

**Предусловие:** Сайт открыт по адресу https://sanflury.github.io/SWAGA-dance/

**Шаги:**
1. Открыть сайт в Chrome
2. Проверить отображение шапки, секции стилей, формы, FAQ, футера
3. Повторить в Firefox
4. Повторить в Safari

**Ожидаемый результат:** Верстка идентична во всех браузерах, нет смещений блоков

**Вид тестирования:** черный ящик, UI-тестирование, кросс-браузерное тестирование
