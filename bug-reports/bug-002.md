## BUG-002: Сайт не адаптирован для мобильных устройств

**Проект:** SWAGA Dance Studio  
**Компонент:** Верстка / Адаптивность  
**Окружение:** iPhone SE (375px), Chrome DevTools  
**Серьезность:** Major  
**Приоритет:** High  
**Статус:** Open  

**Описание:**  
Сайт не соответствует принципу mobile-first. На мобильных устройствах верстка ломается: блоки наезжают друг на друга, текст выходит за границы экрана, кнопки трудно нажать пальцем.

**Шаги воспроизведения:**
1. Открыть https://sanflury.github.io/SWAGA-dance/
2. Открыть DevTools → Toggle device toolbar
3. Выбрать мобильное устройство
4. Пролистать страницу

**Фактический результат:**
- Блоки перекрываются
- Горизонтальный скролл появляется там где его не должно быть
- Навигационное меню отстутвует и не сворачивается в бургер

**Ожидаемый результат:**  
Сайт корректно отображается на мобильных устройствах, блоки адаптируются под ширину экрана

**Примечание:**  
Верстка выполнена без использования Bootstrap и без принципа mobile-first. Известное ограничение текущей версии проекта
